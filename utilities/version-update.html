Version History & MRI Update

Select the root folder once. Procedure 1 appends the new version-history entry to every workbook found; Procedure 2 lists the IDL files and updates the MRI. Files are edited in place — formatting, formulas and macros are preserved.
This tool needs the File System Access API. Open it in Chrome or Edge on desktop.
