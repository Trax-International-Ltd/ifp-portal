Line colours

Defaults follow the UK AIP charts ENR 6-7 (airspace classes) and ENR 6-75 (restrictions and hazards). Written to the COLOR column that AIPCOLOURS reads. Chart black is applied as AutoCAD colour 7.

Load a dataset to list the colour groups.
Block names for points

Written to a BLOCK column in every point shapefile, and used for the DXF inserts. Use the file names of your symbol DWGs, without .dwg. Names are remembered in this browser.
